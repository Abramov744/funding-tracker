# Funding Tracker

Дашборд для поиска монет с устойчивым положительным фандингом на **Aster**, **KuCoin**, **MEXC**, **Gate.io**, **Bybit**, **BingX**, **OKX**, **Crypto.com**, **Hyperliquid** и **dYdX** — под стратегию cash-and-carry (спот лонг + перп шорт).

Только мониторинг: приложение не хранит API-ключи бирж и не открывает позиций. Все данные — публичные market-data эндпоинты.

## Как это работает

- Бэкенд (Node.js + Express, без сборки) каждые 5 минут опрашивает биржи:
  - забирает текущую ставку фандинга по всем бессрочным USDT-парам;
  - для монет с **положительной** текущей ставкой дополнительно тянет историю последних ~200 расчётов фандинга и считает: % положительных периодов, текущий стрик, минимальную/среднюю ставку в окне, APR.
- Фронтенд — статическая страница (`public/`), которую раздаёт тот же сервер. Опрашивает `/api/funding` раз в минуту и позволяет фильтровать/сортировать таблицу на лету.
- Данные хранятся только в памяти процесса — отдельная БД не нужна, т.к. биржи сами отдают историю фандинга по запросу.
- Раз в час подтягивается ранг монеты по капитализации из публичного API CoinGecko (`lib/marketcap.js`) — без API-ключа. Показывается как риск-сигнал: низкий ранг/его отсутствие обычно означает низкую ликвидность и более широкий спред при входе в сделку.

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm start
```

Приложение поднимется на `http://localhost:3000`.

## Деплой на Railway

1. Запушьте репозиторий на GitHub.
2. В Railway: New Project → Deploy from GitHub repo → выберите этот репозиторий.
3. Railway сам определит Node-проект (Nixpacks) и выполнит `npm install` + `npm start`.
4. Никаких переменных окружения не требуется — сервер сам слушает `process.env.PORT`, который Railway подставляет автоматически.
5. После деплоя откройте выданный Railway URL — это и есть дашборд.

## Ограничения / что стоит знать

- **Aster**, **Hyperliquid** и **dYdX** — perp-DEX без встроенного спота: спот-ногу сделки придётся открывать на другой бирже/сети — приложение это не проверяет. MEXC, Gate.io, KuCoin, Bybit, BingX, OKX и Crypto.com — обычные CEX со своим спотом.
- Интервал фандинга у Aster может быть 1ч/4ч/8ч и отличаться по монетам; у MEXC, Gate.io, KuCoin, Bybit, BingX и Crypto.com обычно 8ч, но не всегда; у OKX берётся индивидуально по каждой монете напрямую из ответа биржи (тоже обычно 8ч); у Hyperliquid и dYdX — 1ч.
- **OKX** и **Crypto.com** — у этих бирж нет одного bulk-запроса «ставки фандинга по всем монетам сразу»: приложение опрашивает каждую бессрочную пару отдельно (с ограничением параллелизма), поэтому их опрос при фоновом обновлении заметно тяжелее, чем у остальных бирж.
- Метрики стабильности (`% положительных`, `стрик`, `мин. ставка`) считаются только по монетам, у которых **сейчас** положительная ставка — это соответствует логике входа в стратегию, но исторически стабильные монеты, ставшие отрицательными прямо сейчас, в списке не появятся.
- Перед реальным входом в позицию обязательно проверяйте вручную: ликвидность стакана, наличие и глубину спот-пары, реальные комиссии входа/выхода, лимиты биржи.
