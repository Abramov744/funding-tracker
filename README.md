# Funding Tracker

Дашборд для поиска монет с устойчивым положительным фандингом на **Aster**, **KuCoin**, **MEXC**, **Gate.io**, **Bybit**, **BingX**, **OKX**, **Hyperliquid**, **dYdX**, **edgeX**, **Pacifica**, **Lighter** и **GRVT** — под стратегию cash-and-carry (спот лонг + перп шорт).

Только мониторинг: приложение не хранит API-ключи бирж и не открывает позиций. Все данные — публичные market-data эндпоинты.

## Как это работает

- Бэкенд (Node.js + Express, без сборки) каждые 5 минут опрашивает биржи:
  - забирает текущую ставку фандинга по всем бессрочным USDT-парам;
  - для монет с **положительной** текущей ставкой дополнительно тянет историю фандинга за последние **30 календарных дней** (число запрашиваемых периодов подбирается под интервал фандинга конкретной монеты — 1ч, 4ч или 8ч — так что окно остаётся одинаковым по времени, а не по числу расчётов) и считает: % положительных периодов, текущий стрик, минимальную/среднюю ставку в окне, APR. Если у биржи (или конкретной монеты) реальной истории меньше 30 дней, окно короче — так же, как и раньше.
- Фронтенд — статическая страница (`public/`), которую раздаёт тот же сервер. Опрашивает `/api/funding` раз в минуту и позволяет фильтровать/сортировать таблицу на лету.
- Данные хранятся только в памяти процесса — отдельная БД не нужна, т.к. биржи сами отдают историю фандинга по запросу.
- Раз в час подтягивается ранг монеты по капитализации из публичного API CoinGecko (`lib/marketcap.js`) — без API-ключа. Показывается как риск-сигнал: низкий ранг/его отсутствие обычно означает низкую ликвидность и более широкий спред при входе в сделку.

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm start
```

Приложение поднимется на `http://localhost:3000`.

## Деплой на Railway

1. Запушьте репозиторий на GitHub.
2. В Railway: New Project → Deploy from GitHub repo → выберите этот репозиторий.
3. Railway сам определит Node-проект (Nixpacks) и выполнит `npm install` + `npm start`.
4. Никаких переменных окружения не требуется — сервер сам слушает `process.env.PORT`, который Railway подставляет автоматически.
5. После деплоя откройте выданный Railway URL — это и есть дашборд.

## Ограничения / что стоит знать

- **Aster**, **Hyperliquid**, **dYdX**, **edgeX**, **Pacifica**, **Lighter** и **GRVT** — perp-DEX без встроенного спота: спот-ногу сделки придётся открывать на другой бирже/сети — приложение это не проверяет. MEXC, Gate.io, KuCoin, Bybit, BingX и OKX — обычные CEX со своим спотом.
- Интервал фандинга у Aster может быть 1ч/4ч/8ч и отличаться по монетам; у MEXC, Gate.io, KuCoin, Bybit и BingX обычно 8ч, но не всегда; у OKX берётся индивидуально по каждой монете напрямую из ответа биржи (тоже обычно 8ч); у Hyperliquid, dYdX, Pacifica и Lighter — 1ч; у edgeX — 4ч; у GRVT интервал приходит индивидуально по каждой монете в самом ответе (обычно 8ч, но может быть 1ч/4ч).
- **edgeX**, **Pacifica**, **Lighter** и **GRVT** торгуют не только крипто-бессрочниками, но и токенизированными акциями/commodities/forex/RWA под теми же "рынками" (TSLA, XAU, EURUSD, US500 и даже ANTHROPIC/OPENAI) — такие инструменты исключены из сканера, он только про крипту.
- У edgeX и Pacifica биржа сама помечает такие инструменты отдельным полем, а у Lighter и GRVT (как и у Orderly) **никакого признака нет** — все поля у `AAPL_USDT_Perp` и `BTC_USDT_Perp` идентичны. Для них работает `lib/cryptoassets.js`: тикер должен найтись в карте CoinGecko (топ-1500, откуда выброшены токенизированные акции вроде «NVIDIA • Robinhood Token»), **и** цена перпетуала должна сойтись с ценой монеты — это ловит совпадения тикеров в обе стороны (биржевой `META` за $600 против монеты MetaDAO за $5.57, и наоборот — `SPX` это мемкоин SPX6900, а не индекс). Проверено на реальных выгрузках: 75/75 на Pacifica и 132/138 на Orderly без единой просочившейся акции.
- **GRVT** — рыночные данные отдаются не GET-запросами с параметрами, а POST-запросами с JSON-телом; ставка фандинга приходит в процентных пунктах (`"0.01"` = 0.01%, не 0.01 долей), а время расчёта — в unix-наносекундах.
- **OKX** — у этой биржи нет одного bulk-запроса «ставки фандинга по всем монетам сразу»: приложение опрашивает каждую бессрочную пару отдельно (с ограничением параллелизма), поэтому её опрос при фоновом обновлении заметно тяжелее, чем у остальных бирж.
- Метрики стабильности (`% положительных`, `стрик`, `мин. ставка`) считаются только по монетам, у которых **сейчас** положительная ставка — это соответствует логике входа в стратегию, но исторически стабильные монеты, ставшие отрицательными прямо сейчас, в списке не появятся.
- Перед реальным входом в позицию обязательно проверяйте вручную: ликвидность стакана, наличие и глубину спот-пары, реальные комиссии входа/выхода, лимиты биржи.
