# Funding Tracker

Дашборд для поиска монет с устойчивым положительным фандингом на **Aster**, **MEXC** и **Gate.io** — под стратегию cash-and-carry (спот лонг + перп шорт).

Только мониторинг: приложение не хранит API-ключи бирж и не открывает позиций. Все данные — публичные market-data эндпоинты.

## Как это работает

- Бэкенд (Node.js + Express, без сборки) каждые 5 минут опрашивает биржи:
  - забирает текущую ставку фандинга по всем бессрочным USDT-парам;
  - для монет с **положительной** текущей ставкой дополнительно тянет историю последних ~100 расчётов фандинга и считает: % положительных периодов, текущий стрик, минимальную/среднюю ставку в окне, APR.
- Фронтенд — статическая страница (`public/`), которую раздаёт тот же сервер. Опрашивает `/api/funding` раз в минуту и позволяет фильтровать/сортировать таблицу на лету.
- Данные хранятся только в памяти процесса — отдельная БД не нужна, т.к. биржи сами отдают историю фандинга по запросу.

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm start
```

Приложение поднимется на `http://localhost:3000`.

## Деплой на Railway

1. Запушьте репозиторий на GitHub.
2. В Railway: New Project → Deploy from GitHub repo → выберите этот репозиторий.
3. Railway сам определит Node-проект (Nixpacks) и выполнит `npm install` + `npm start`.
4. Никаких переменных окружения не требуется — сервер сам слушает `process.env.PORT`, который Railway подставляет автоматически.
5. После деплоя откройте выданный Railway URL — это и есть дашборд.

## Ограничения / что стоит знать

- **Aster** — это perp-DEX без встроенного спота: спот-ногу сделки придётся открывать на другой бирже/сети — приложение это не проверяет.
- Интервал фандинга у Aster может быть 1ч/4ч/8ч и отличаться по монетам; для MEXC и Gate обычно 8ч, но не всегда.
- Метрики стабильности (`% положительных`, `стрик`, `мин. ставка`) считаются только по монетам, у которых **сейчас** положительная ставка — это соответствует логике входа в стратегию, но исторически стабильные монеты, ставшие отрицательными прямо сейчас, в списке не появятся.
- Перед реальным входом в позицию обязательно проверяйте вручную: ликвидность стакана, наличие и глубину спот-пары, реальные комиссии входа/выхода, лимиты биржи.
