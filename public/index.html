Данные — публичные market-data API бирж. Инструмент только для мониторинга: приложение не хранит ключи и не открывает позиции. Перед входом в стратегию всегда проверяйте вручную ликвидность, наличие спот-пары и реальную комиссию входа/выхода.

* Ранг по капитализации, а также цены на споте в попапе графика берутся из публичного API CoinGecko (официальный CoinMarketCap API требует платной/зарегистрированной подписки с собственным ключом). Список бирж в блоке "где купить на споте" — до 10 бирж с наибольшим объёмом торгов именно этой монетой за 24 часа по данным CoinGecko, а не фиксированный список топовых площадок.

** Открытый интерес (OI) — суммарный номинал открытых позиций по этому конкретному перпетуалу именно на этой бирже; в отличие от ранга CMC, показывает ликвидность именно этого рынка, а не капитализацию всего проекта.

Вкладка «Фьючерс + фьючерс» ищет пары бирж по одной монете, где выгодно быть в шорте на одной и в лонге на другой — дельта-нейтрально, без спотовой ноги и без риска цены самой монеты. Но капитал нужен на двух биржах одновременно, комиссии/маржа считаются отдельно на каждой, а цены на двух биржах могут немного расходиться (базисный риск) — перед входом сверяйте это вручную.
